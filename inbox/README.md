# 收件箱（inbox）— 新文件怎么进系统

## 用法
1. **直接把文件丢进对话框**（PDF / Word / 扫描件都行），告诉我"处理这份"。
2. 我走这条线（全程不写生成脚本，理解/出题/材料 100% 由大模型 + 技能完成）：
   - **L1 抽取**：`doc2kb` 技能把 PDF/Word 抽成文本块（纯提取，不做判断）
   - **L2 理解**：我（LLM）把文本编译为结构化 KU（知识点），落 `kb/`
   - **L3a 题库**：我 + `standards-exam-generator` 技能出选择/判断/填空/计算题，落 `rules/`
   - **L3b 材料**：我直接产出闪卡/参数表/自测/易错点，落 `materials/`
   - **L4–L6 消费**：判分脚本、出卷、学习页全部是确定性消费，不调大模型
3. 也可以把文件先放到本 `inbox/` 目录，再在对话里说"处理 inbox 里的 XXX"。

## 入库硬规则（搬自历史踩坑）
- 🚫 **停下**：抽到的文本全是水印/水印网址/与正文无关字符（无真实内容层）→ 让你去下干净版。
- ✅ **继续**：pdfplumber 抽 0 字符但文件体积大（数 MB，是图片）→ 走 Docling OCR。
- ⚠️ OCR 已知限制：单页 >120s 超时整页丢失；公式区标 `[公式区域需 VLM]`；标题页/前言偶被并入首条。这些属可接受噪点，正式库须人工过一遍。

## 质量不好的文件怎么办
- 若你已知道某份是水印垃圾，**先去重下干净版再给我**，别让我在垃圾上建 KU。
- 若我抽到垃圾，会立刻停下并提示你重下，不会硬编。
